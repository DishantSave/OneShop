Authentication & Endpoint Overview

All GraphQL queries are exposed over HTTP POST at /graphql. Authenticate external requests using either header below:

Option 1: Custom API Key Header (Recommended for ERP/WMS) 
X-API-Key: osh_live_xxxxxxxxxxxxxxxxxxxxxx
Option 2: Standard Bearer Token Header 
Authorization: Bearer <API_TOKEN>

QUERY

orders(companyCode: String, status: String): [OrderDto]

Retrieve customer & wholesale orders with nested line items, tax computations, discount breakdown, and fulfillment statuses.

Arguments (Filters)
  • companyCode (String, optional): Filter by registered company identifier.
  • status (String, optional): E.g. Pending, Confirmed, Shipped, Delivered.
Return Fields
orderId, companyCode, customerName, customerEmail, totalAmount, subTotal, tax, discount, shippingCost, shippingAddress, shippingState, deliveryPartner, items [...]
cURL Request 
{{ getEndpointCurl('orders', 'query { orders { orderId customerName totalAmount status } }') }}
QUERY

shippingLabels(companyCode: String): [ShippingLabelDto]

Logistics labeling & dispatch data including AWB tracking numbers, assigned carrier partners (DHL, FedEx, BlueDart), fulfillment facilities, parcel weight & box dimensions.

Dispatch Label Attributes
  • trackingNumber: Real-time carrier AWB (e.g. AWB-BLUEDART-100234)
  • trackingUrl: Direct click-to-track carrier URL
  • packageWeight & packageDimensions: Logistics specs (e.g. 1.45 kg, 25x18x10 cm)
  • facilityType & facilityCode: Origin warehouse or retail dispatch store
Single Order Lookup Resolver
shippingLabelByOrderId(companyCode: String!, orderId: String!): ShippingLabelDto

Directly retrieve the physical box barcode label for a target order number.

JavaScript (Fetch) Example 
{{ getEndpointJs('query { shippingLabels { orderId trackingNumber deliveryPartner packageWeight } }') }}
